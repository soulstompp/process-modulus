What the corpus actually says, and whether anything is looking.

> **Também disponível em português europeu:** `pt-PT/examples/observations/README.md`.

This program asks the corpus questions and prints the answers. Some relations produce knowledge
rather than a verdict, and without a program to print them nobody would read them. Every figure a
comment in this repository might quote is printed here instead, because a figure written into a
header is right on the day it is written and answers to nothing after that.

It asserts only that something is asked, never what the answer is:

- **nothing is reached by nothing.** Every query is read by another query or a program, and every
  document is loaded or read by a test. A query nothing reads fails the run.
- **every remainder has been asked who might be carrying it,** whether that set of holders is
  bounded and whether the pairs in it were tested.

Neither judges a filing. A remainder nobody bounded is the honest state for a document written to
argue about three layers. A spillover onto another layer is a referral, for a person to settle.

## A zero and a blank

Where a figure can say the empty case itself, a blank must not say it too. A blank carries no unit,
no author and no origin, so a receiver cannot compare it with the filers who wrote a number.

- A slack of zero is filed as `[0, 0, 0]` in its own unit, never as a blank.
- A supply that runs all the time is filed as a window of one whole period, with the origin that
  says who could shorten it. It might run all the time because it cannot stop, because somebody
  promised it would, or because somebody staffed it, and a blank would lose which.
- A remainder of zero is a `clearance` fit with a quantity of `[0, 0, 0]`, because a blank would
  lose the fit and the holders.

A blank may stand for the value only where the document already fixes it and nothing else is lost.
A conversion between two identical units needs no factor, and a rule confines the missing factor to
exactly that case.

Where nothing has a size, a unit or an author, the whole vocabulary of blanks stays. Examples are
no buffer absorbing the remainder, nobody setting a bound, and somebody looking for couplings and
finding the layers independent. One of the sections shows which blanks each question has actually
taken.

## Running it

It needs the database, reads it, and writes nothing:

```text
DATABASE_URL="postgres://$USER@localhost/process_modulus?host=/var/run/postgresql" \
  cargo run --example observations
```
